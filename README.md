# Project Skeleton

A minimal frontend project foundation for future development. This initial version contains only the engineering structure and reusable infrastructure, without project-specific content or visual design.

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- React Router
- ESLint
- Prettier

## Getting Started

Requirements:

- Node.js 20 or later
- npm

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

## Available Scripts

```bash
npm run dev
npm run typecheck
npm run lint
npm run format:check
npm run build
npm run preview
```

## Project Structure

```text
public/             Static public assets
src/
  assets/           Source assets
  components/       Shared and reusable components
  constants/        Application constants
  data/             Data modules
  hooks/            Reusable React hooks
  layouts/          Shared page layouts
  lib/              Shared libraries and helpers
  pages/            Route-level pages
  router/           Route configuration
  styles/           Global styles and design tokens
```
